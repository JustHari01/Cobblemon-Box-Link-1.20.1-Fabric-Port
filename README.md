# Cobblemon Box Link (Unofficial 1.20.1 Fabric Backport)

This unofficial backport brings Cobblemon Box Link to Minecraft 1.20.1 with Fabric. It adds a craftable Box Link that lets a player open their Cobblemon PC remotely.

## Features

- Use the Box Link item to open PC storage from anywhere outside a battle.
- Press the default `\` keybind to open the PC while the Box Link is in the inventory.
- Optional Accessories and Trinkets slot support.
- Server configuration can allow the keybind without carrying or equipping the item. The default requires the item.

The configuration file is `config/cobblemonboxlink.json`. The Box Link item and its crafting recipe use the original project assets and data.

## Requirements

- Minecraft 1.20.1
- Fabric Loader and Fabric API
- Cobblemon 1.5.2 for Minecraft 1.20.1
- Optional: Accessories 1.0.0-beta.47 or newer, or Trinkets 3.7.2, for accessory-slot support
- Java 17 or newer
